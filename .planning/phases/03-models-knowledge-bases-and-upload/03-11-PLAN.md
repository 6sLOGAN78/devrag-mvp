<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> credential lookup | tenant id and model id decide whose key is used |
| bundle -> provider | the decrypted key leaves the process in one request |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11-01 | Information disclosure | using another tenant's credential | mitigate | credential lookup filters by tenant id; foreign model id returns NOT_FOUND (integration test) |
| T-03-11-02 | Information disclosure | key in repr, logs, exceptions | mitigate | key only inside the driver, `repr` without it, caplog scan, no `str(exc)` |
| T-03-11-03 | Tampering | provider changing vector size mid-life | mitigate | `expected_dimension` check raises before usage is recorded |
| T-03-11-04 | Tampering | lost or doubled usage counts on stream or retry | mitigate | one `add_used_tokens` call after success; retry and stream tests assert exact totals |
| T-03-11-05 | Denial of service | event-loop blocking by sync drivers | accept | the bundle is blocking by contract and callers run it in their bounded executor; documented in the module docstring |
| T-03-11-06 | Information disclosure | tampered ciphertext revealing partial plaintext | mitigate | AES-GCM tag failure maps to `key_unreadable` with a fixed message |
</threat_model>
