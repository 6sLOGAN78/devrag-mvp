# Frontend Tests

## Level 1: Conceptual Explanation

Frontend testing validates the React user interface (`/web`), ensuring UI components, agent canvas workflows, document upload widgets, and chat dialog components render correctly and handle user interactions cleanly without runtime JavaScript errors.

---

## Level 2: Implementation Details

### Frontend Testing Framework

- **Tooling**: Node.js, npm/pnpm, React Testing Library, and Jest / Vitest.
- **Location**: `/web/src/__tests__/` or co-located `.test.tsx` / `.spec.tsx` files.
- **Execution Command**:
  ```bash
  cd web
  npm run test
  ```
