## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-75 | S | OTP brute force | mitigate | 6 digits, 5 attempts then invalidation, per-email and per-IP limits, 10-minute TTL (D-06) |
| T-02-76 | I | account enumeration via reset | mitigate | identical response body and similar latency; nothing sent for unknown email; limits consumed either way (D-07) |
| T-02-77 | I | code readable from Redis | mitigate | only salted HMAC stored, keyed by SECRET_KEY |
| T-02-78 | T | email header injection | mitigate | CR/LF and address validation, fixed templates |
| T-02-79 | E | reset without verification | mitigate | verified marker required, 5-minute TTL, consumed once |
| T-02-80 | E | session surviving reset | mitigate | access_token rewritten to INVALID_ in the same transaction (D-08) |
| T-02-81 | D | mail flooding and hanging SMTP | mitigate | rate limits, bounded worker pool, dial and send timeouts, fail closed on Redis loss |
| T-02-82 | I | SMTP credentials in logs or over plaintext | mitigate | refuse auth with security none, redacted config, no body logging |
