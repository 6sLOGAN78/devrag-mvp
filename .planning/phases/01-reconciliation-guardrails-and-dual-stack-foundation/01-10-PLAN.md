    - success: envelope `{code:0, message:"", data:{a:1}}` resolves to `{a:1}`
    - failure: HTTP 200 or 4xx with `{code:101, message:"bad"}` rejects `ApiError` with code 101, status, message `bad`; toast shown once with title `Request failed` and description `bad`; with `{silent:true}` no toast
    - description rule: server message used only when non-empty string of at most 160 characters, else the fallback; stack-like or SQL-like content never shown (only the message string); `Code {code}` line included
    - 401: token removed from localStorage, user store reset, query client cache cleared, one toast `Session expired` / `Your session ended. Reload the page to continue.`; a second identical 401 updates rather than stacks (same toast id); no navigation because no `/login` route exists yet
    - 5xx without parseable envelope: ApiError code -1, toast `Server error` / `The server hit a problem. Try again in a moment.`; network error: status 0, `Can't reach the server`; timeout 10 s default: `Request timed out`
    - token present: header `Authorization: Bearer <token>` on every request; absent: no header
    - `requestWithMeta` returns `{data, source}` where `source` is the `x-api-source` response header
    - ApiError carries `data` from the envelope (health 503 payloads need it)
  </behavior>
