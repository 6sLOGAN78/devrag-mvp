| Boundary | Description |
|----------|-------------|
| API response -> DOM | provider names, model ids and URLs come from the server and users |
| role -> visible credential data | the SPA must not display what the API withholds |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-20-02 | Information disclosure | members seeing mask, last4 or addresses | mitigate | credential line rendered only for owner and admin; page test as normal member |
| T-03-20-03 | Tampering | stored XSS through model ids or URLs | mitigate | text nodes only; no `dangerouslySetInnerHTML` (grep in acceptance) |
