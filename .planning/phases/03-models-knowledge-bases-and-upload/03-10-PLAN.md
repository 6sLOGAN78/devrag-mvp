## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin input -> outbound request | base URL, model ids and key come from the request body |
| provider -> service | error text, status codes and vector sizes are untrusted |
| service -> Valkey | the limiter must not become an availability bypass |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-10-01 | Information disclosure | SSRF through the base URL (metadata, es01, minio, mysql, userinfo) | mitigate | `validate_base_url` with `internal_hosts`, `allow_private` from settings, zero-request assertions in test_provider_service.py |
| T-03-10-02 | Information disclosure | saved key sent to a new address chosen by an admin, including when the saved key is shorter than 8 characters and `last4` is empty | mitigate | `key_required_for_new_address` rule in `check_request` keyed on `InstanceInfo.has_key` (sealed envelope present), never on `last4`; unit case with `has_key=True, last4=""` and integration case with a 5-character key proving zero requests reach the new address |
| T-03-10-10 | Denial of service | composite model id over 128 characters passing the save and then failing the default or dataset write with a data-too-long 500 | mitigate | `check_model_names` bound in `check_request` and `add_models` (`models_invalid`), on top of the `save_instance` bound of plan 03-09 |
| T-03-10-03 | Information disclosure | key or provider body in messages, logs, views | mitigate | safe_message only, no `str(exc)`, DTO builders without key fields, window scan of every returned structure |
| T-03-10-04 | Elevation of privilege | non-elevated callers (normal members, API and beta tokens) receiving address or last4 | mitigate | `include_credentials` is set by the handler from `scope.subject in {owner, admin}` (plan 03-12), never from the inherited role; DTO test for both values |
| T-03-10-09 | Information disclosure | a rotated key leaving older envelopes of the same instance in use | mitigate | upserting `save_instance` re-seals every row of the instance in one transaction; rotation integration case opens every row with the new key |
| T-03-10-05 | Denial of service | save used as a provider-call amplifier | mitigate | per-workspace Valkey window, at most two tests per save, call timeout 20 s, retries 0 |
| T-03-10-06 | Denial of service | limiter outage disabling the limit | mitigate | fail closed: `rate_limit_unavailable`, no provider request |
| T-03-10-07 | Tampering | provider returning an absurd vector size | mitigate | dimension bound 1..4096 before storing |
| T-03-10-08 | Spoofing | provider 401 mistaken for a session failure | mitigate | provider authentication errors map to `provider_refused` (HTTP 400 in plan 03-12), never to an auth reason |
