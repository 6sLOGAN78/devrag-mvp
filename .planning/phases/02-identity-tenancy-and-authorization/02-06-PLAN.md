## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> token verifier (Go and Python) | attacker-supplied bearer string |
| database -> password verifier | stored hashes of mixed origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-18 | S | token forgery or tampering | mitigate | HMAC-SHA1 with >= 32 char secret, constant-time compare, length cap 1024 before HMAC, tamper and wrong-secret vectors on both stacks |
| T-02-19 | S | expired or future-dated token replay | mitigate | 30-day max age, age < 0 rejected, boundary vectors (SEC-09) |
| T-02-20 | E | signed non-string payload accepted as identity | mitigate | verifier requires JSON string; vector `signed_non_string_payload_number` |
| T-02-21 | I | scrypt or unsalted hash writes making users unable to log in or weakening storage | mitigate | explicit pbkdf2 method, prefix test, Go rejects other schemes |
| T-02-22 | D | PBKDF2 CPU exhaustion | mitigate | semaphore sized to CPUs, password length cap 128 |
| T-02-23 | S | zlib bomb in payload | mitigate | io.LimitReader 4096 on inflate, 1024 char token cap |
</threat_model>
