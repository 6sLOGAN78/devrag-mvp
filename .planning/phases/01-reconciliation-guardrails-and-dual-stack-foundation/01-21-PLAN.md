<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator config -> container runtime | TLS and port settings decide whether credentials travel in clear text |
| host bind mount -> dropped-UID processes | log directory ownership decides whether services can start |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Information disclosure | silent HTTP fallback when NGINX_TLS=1 (WR-12) | mitigate | prepare_runtime.sh exits 1 before Nginx starts; unit tests for missing/partial certs |
| T-21-02 | Denial of service | restart loop on root-owned LOG_DIR (WR-11) | mitigate | `chown APP_UID:APP_GID` in prepare_runtime.sh; test asserts the chown call |
| T-21-03 | Repudiation | healthy status while a backend is hung (WR-13) | mitigate | healthcheck probes both backends directly with 200-only rule; tests |
| T-21-04 | Denial of service | misconfigured GO_API_PORT yields 502 on all Go routes (WR-14) | mitigate | port pinned in compose; env example no longer offers it |
| T-21-05 | Spoofing | `curl -k` in wait_stack against self-signed cert | accept | loopback probe only (127.0.0.1), readiness check, no credentials sent |
</threat_model>
