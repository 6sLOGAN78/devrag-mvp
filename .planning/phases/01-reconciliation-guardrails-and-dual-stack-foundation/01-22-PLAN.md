| Boundary | Description |
|----------|-------------|
| HTTP client -> Quart error handlers | client-controlled failures (oversize body, bad method) produce status and envelope |
| migration code -> database | DDL and version bookkeeping must target the same database |

| T-22-03 | Tampering | unique constraint silently not created | mitigate | uniqueness-aware index helper raises on mismatch |
| T-22-04 | Denial of service | daemon hooks silently never run (WR-07) | mitigate | hooks execute on the serving loop; survival test |
| T-22-05 | Information disclosure | error messages | accept | messages stay generic; no input echoed (SEC-10 unchanged) |
