|-----------|----------|-----------|-------------|-----------------|
| T-02-54 | I | account enumeration through login copy | mitigate | pinned fallback key for every login failure, server message never shown for login |
| T-02-55 | S | open redirect after login | mitigate | sanitiseNext on `next` (tested in plan 02-12) |
| T-02-56 | I | password retained in DOM, URL, cache or logs | mitigate | cleared after failure, autocomplete attributes, never in query keys or URLs; unit test asserts query cache holds no password |
| T-02-57 | T | XSS through nickname or server messages | mitigate | React text rendering only, no raw HTML, server message length-capped to 160 characters |
| T-02-58 | E | sign-up shown when disabled | mitigate | fail-closed on config loading or error; server also refuses (plan 02-09) |
