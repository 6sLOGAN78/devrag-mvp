# Vector Search Engine

## Level 1: Conceptual Overview

Vector Search performs K-Nearest Neighbors (KNN) retrieval in high-dimensional vector spaces using dense embeddings generated by embedding models. It captures semantic context, allowing queries to match passages with similar meaning even when exact words differ.

## Level 2: Implementation Details

### Dense Vector Expression

Implemented in [rag/nlp/search.py](file:///home/logan78/Desktop/ragflow/rag/nlp/search.py#L55-L63):

```python
async def get_vector(self, txt, emb_mdl, topk=10, similarity=0.1):
    qv, _ = await thread_pool_exec(emb_mdl.encode_queries, txt)
    embedding_data = [get_float(v) for v in qv]
    vector_column_name = f"q_{len(embedding_data)}_vec"
    return MatchDenseExpr(vector_column_name, embedding_data, "float", "cosine", topk, {"similarity": similarity})
```

### Mathematical Formula: Cosine Similarity

$$\text{Cosine}(\vec{Q}, \vec{D}) = \frac{\vec{Q} \cdot \vec{D}}{\|\vec{Q}\|_2 \|\vec{D}\|_2} = \frac{\sum_{i=1}^{d} Q_i D_i}{\sqrt{\sum_{i=1}^{d} Q_i^2} \sqrt{\sum_{i=1}^{d} D_i^2}}$$
