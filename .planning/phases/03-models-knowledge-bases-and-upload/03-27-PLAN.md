## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| docker/.env -> test process | the one place the real key is read |
| test process and app container -> OpenRouter | real outbound calls with the user's key |
| gate scripts -> logs | no key may reach shell output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-27-01 | Information disclosure | key in shell environment, process list, test output or assertion messages | mitigate | read only via `stack_env()` inside Python, never exported; no f-strings with the value; step command has no key; guard tests grep non-comment lines |
| T-03-27-02 | Information disclosure | key in responses or container logs | mitigate | recording wrapper plus compose log scan with window matching (counts only) |
| T-03-27-03 | Denial of service | cost or rate-limit exposure from live calls | mitigate | budget constants (6 chat-class, 3 embedding), cheapest models, tiny prompts (D-05) |
| T-03-27-04 | Repudiation | a missing key silently skipping the live tier | mitigate | fixture fails with a fixed message; `skip` and `xfail` absent (grep); gate step fails |
| T-03-27-05 | Information disclosure | secret committed through the scripts or fixtures | mitigate | `check_secrets.py` run; bad key assembled from parts; example env keeps the variable empty |
