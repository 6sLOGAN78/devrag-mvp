| Boundary | Description |
|----------|-------------|
| browser -> arbitrary host | callers may pass absolute URLs (presigned MinIO, avatars, user-supplied endpoints) through the shared client |
| server response -> client auth state | a 401 can arrive for a stale or credential-less request |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Information disclosure | Authorization header on cross-origin URLs (WR-22) | mitigate | `isSameOrigin` gate; tests for absolute, other-origin and protocol-relative URLs |
| T-18-02 | Denial of service / Tampering | stale 401 wipes a fresh session (WR-21b) | mitigate | purge only when sent token equals current token; test |
| T-18-03 | Spoofing / UX | wrong-password 401 shown as expired session (WR-21a) | mitigate | no purge without a sent token; server message toast; test |
| T-18-04 | Information disclosure | server message echoed in toast | accept | existing `safeMessage` length/shape guard is unchanged |
</threat_model>
