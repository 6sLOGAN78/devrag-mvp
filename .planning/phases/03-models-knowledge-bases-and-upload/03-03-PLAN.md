## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser localStorage -> store | a stored tenant id is untrusted input |
| store -> API requests | the active tenant id is later sent as `tenant_id` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Elevation of privilege | forged localStorage tenant id | mitigate | the store accepts a stored tenant only if it is in the server-provided membership list for that user; the server (plan 03-04 tenant_scope) is authoritative and answers 404 for any other id |
| T-03-03-02 | Information disclosure | another user's stored workspace after account switch | mitigate | entry keyed with userId; mismatch ignored; sign-out resets the store |
| T-03-03-03 | Tampering | workspace or owner name rendered as HTML | mitigate | rendered as text nodes only; no dangerouslySetInnerHTML (grep in acceptance) |
</threat_model>
