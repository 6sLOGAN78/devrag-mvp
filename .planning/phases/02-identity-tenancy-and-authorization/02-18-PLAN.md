## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user -> reset forms | email, code and new password |
| UI copy -> user | text that could confirm account existence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-83 | I | UI confirms whether an account exists | mitigate | fixed copy "If an account exists..." and unconditional advance on 2xx (D-07) |
| T-02-84 | S | OTP brute force from the UI | mitigate | server limits (plan 02-17); UI returns to step 1 on invalidation, countdown mirrors the 60 s limit |
| T-02-85 | I | code or password in URL, logs or query cache | mitigate | component state only, silent requests, no URL state |
| T-02-86 | T | XSS through echoed email or server message | mitigate | text rendering only, server message length cap 160 |
</threat_model>
