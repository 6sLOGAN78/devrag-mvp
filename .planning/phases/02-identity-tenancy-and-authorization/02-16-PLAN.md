| user-selected file -> browser canvas -> API | image bytes and size |
| profile text -> DOM | nickname and avatar rendering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-71 | T | XSS via nickname or avatar | mitigate | text rendering only, avatar only inside img src as a validated data URL, no raw HTML (grep gate) |
| T-02-72 | E | session left valid after password change | mitigate | local purge and server rewrite (plan 02-15), live test asserts 401 for the old token |
| T-02-73 | I | password retained in form state or cache | mitigate | fields reset after submit, never in query keys |
| T-02-74 | T | oversized or disguised image upload | mitigate | client magic-byte check and 256 KB cap mirrored by the server validator |
</threat_model>
