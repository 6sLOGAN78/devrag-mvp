| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-49 | S | open redirect after login via `next` | mitigate | sanitiseNext allows only a single-slash path; unit cases for //, /\\, schemes |
| T-02-50 | I | signed-out visitor seeing guarded UI | mitigate | guard renders skeleton or redirect only, never the shell before recovery |
| T-02-51 | E | stale 401 purging a fresh session | mitigate | sentToken guard retained and tested |
| T-02-52 | I | XSS reading the localStorage token | accept | R-35 default trade-off; no raw HTML rendering anywhere (grep gate), recorded in R-107/R-35 notes |
