Provide `assert_unchanged(validated: ValidatedUrl, url: str, *, allow_private, deny_hosts, resolve)` that re-validates at call time (DNS rebinding check) and raises UnsafeBaseUrl if the resolved addresses are no longer all allowed. ## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Information disclosure | SSRF through base URL (metadata, es01, minio, mysql) | mitigate | validate_base_url denies link-local, metadata, internal service names always and private ranges unless configured; all spellings judged after resolution |
| T-03-02-02 | Tampering | DNS rebinding between save and call | accept | re-validation with assert_unchanged at call time; connection-time pinning is not possible with the SDK clients; residual window recorded in DECISIONS (plan 03-28) |
| T-03-02-03 | Information disclosure | key text inside SDK exception messages and URLs in logs | mitigate | shape-based redaction in Python, Go and Nginx with shared vectors |
| T-03-02-04 | Denial of service | ReDoS in the new redaction stage | mitigate | bounded quantifiers, RE2 in Go, hostile-line timing test extended |
</threat_model>
