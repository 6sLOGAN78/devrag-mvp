## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-31 | S | credential stuffing and brute force on login | mitigate | per-email and per-IP Redis limits before hashing (configurable, production defaults 5/15 min and 30/15 min per R-94), 429 with Retry-After, fail closed (D-04, D-29) |
| T-02-32 | I | account enumeration via login message or timing | mitigate | one generic message, dummy PBKDF2 verify for unknown and disabled accounts, identical status |
| T-02-33 | I | account enumeration via registration duplicate error | accept | documented API needs the error; rate limited 10/hour per IP; recorded as R-107 |
| T-02-34 | T | partial registration leaving orphan rows | mitigate | single transaction, rollback test |
| T-02-35 | D | PBKDF2 CPU exhaustion | mitigate | limit before hash, semaphore, 128 character cap, 1 KiB body cap |
| T-02-36 | I | password or hash in response, logs | mitigate | DTOs only, no body logging, leak test |
| T-02-37 | S | spoofed client IP defeats per-IP limits | mitigate | X-Real-IP honoured only from a loopback peer, otherwise the socket peer; X-Forwarded-For never read; spoofed-header unit test |
| T-02-38 | T | login race issuing two tokens | mitigate | conditional UPDATE then re-read, parallel login test |
