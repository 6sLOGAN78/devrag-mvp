## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> adapter | index names, dataset ids and filter conditions are untrusted until validated |
| adapter -> Elasticsearch | credentials from settings; response bodies may carry host detail |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08-01 | Information disclosure | wildcard or comma index name, empty `dataset_ids`, missing kb filter reading another tenant's chunks | mitigate | `validate_index_names` regex, `require_dataset_ids`, kb_id term AND-ed in every query; contract tests for each refusal and a two-dataset isolation test |
| T-03-08-02 | Tampering | empty condition turning delete or update into match-all | mitigate | `require_condition`; no `match_all` in the module (grep in acceptance) |
| T-03-08-03 | Tampering | injection through condition keys or script text | mitigate | key regex, painless script with parameters only, values never formatted into scripts |
| T-03-08-04 | Information disclosure | engine error text or host name in exceptions | mitigate | DocStoreError carries a fixed operation message only |
| T-03-08-05 | Denial of service | oversized k or from+size, hung engine | mitigate | k and size caps, `request_timeout=30`, `max_retries=0`, bounded executor in callers |
| T-03-08-06 | Tampering | half-failed bulk from a zero or wrong-size vector | mitigate | pre-insert vector checks raise before the bulk call |
</threat_model>
