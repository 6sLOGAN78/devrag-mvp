Replace the quadratic/cubic Python log redactor with a linear-time scan, close the remaining redaction misses in both engines, and truncate untrusted fields at the log site.

Purpose: CR-02 is reachable without credentials (a 2,500 character path took 14.8 s); every later auth route logs request data through this code.
Output: linear redactor, extended shared vectors, timing-bound tests, Go mirror of the new vectors, truncated path logging.
</objective>

  <files>common/log_utils.py, api/apps/middleware.py, test/testcases/test_request_log.py</files>

  </read_first>
  <action>Rewrite redact_text in common/log_utils.py per D-31 as a two-stage scan: (1) a compiled KEYSEP pattern `(?<![\w-])(?P<key>["']?[\w-]+["']?)(?P<sep>[ \t]*[=:][ \t]*)` finds each word run followed by a separator; (2) when the key contains a sensitive word (password, passwd, pwd, secret, token, api[_-]?key, authorization, cookie, set-cookie and the existing list) match the value with a bounded pattern anchored at that position: quantifiers capped at {0,4096}, quoted values escaped-quote aware, an optional auth scheme word (Bearer, Basic, Digest, Token, ApiKey, Api-Key, Negotiate, AWS4-HMAC-SHA256) before the credential; cookie and set-cookie values consume to end of line; the consumed span is skipped so later matches inside it are not rescanned. (3) URL userinfo is handled by a linear scan with no nested quantifiers: a compiled scheme finder `(?<![a-z0-9+.-])[a-z][a-z0-9+.-]*://` locates each `//`; from there the authority ends at the first of `/`, `?`, `#` or whitespace (found with a single pass or `str.find` per delimiter, not a regex, and capped at 4096 characters so a hostile authority cannot cause repeated long scans); `rfind('@')` inside that authority gives the LAST `@`; when the userinfo before it contains a `:` the whole span from just after `//` up to that last `@` is replaced by the redaction marker and scanning resumes after it. This covers an empty user and a password containing `@` with no tail left behind (the amqp vector keeps no tail). The Go mirror uses the RE2 pattern `(?i)([a-z][a-z0-9+.-]*://)[^\s/?#]*:[^\s/?#]*@` replaced to keep the scheme only (RE2 is linear and its greedy class stops at the last `@` of the authority). Cap input to redact_text at 64 KiB (the remainder replaced with a truncation marker) as defence in depth. In api/apps/middleware.py truncate the request path and any other client-controlled logged field to 512 characters with a `[truncated]` marker before logging. Add a request-level test in test_request_log.py that sends an 8 KB path through the real app test client and asserts the response completes within a generous bound (2 s) and the logged path carries the marker. The 12 original vectors must still pass unchanged.</action>
