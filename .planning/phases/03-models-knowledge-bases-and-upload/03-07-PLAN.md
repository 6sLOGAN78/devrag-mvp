## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied key -> filesystem | a key reaches the local driver |
| server -> MinIO | credentials from settings |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07-01 | Tampering | path traversal through key or bucket in the local driver | mitigate | validate_key, bucket regex, resolve() plus is_relative_to, symlink test, server-generated keys only |
| T-03-07-02 | Information disclosure | guessing another tenant's object key | mitigate | 128-bit random uuid key under the tenant prefix; keys are never derived from names |
| T-03-07-03 | Information disclosure | presigned URL leaking the internal endpoint or granting long access | accept | implemented and tested with 3600 s expiry, not exposed by any route in Phase 3; recorded in DECISIONS (plan 03-28) |
| T-03-07-04 | Denial of service | partial writes and orphan temp files | mitigate | O_EXCL temp file, os.replace, unlink on failure; crash test |
| T-03-07-05 | Information disclosure | credentials or keys in storage error messages | mitigate | StorageError messages name operation and bucket only |
</threat_model>
