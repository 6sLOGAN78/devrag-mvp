| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-30-01 | Tampering | stored XSS through dataset name or description | mitigate | text nodes only; no `dangerouslySetInnerHTML` (grep); card link href built from the id only |
| T-03-30-02 | Information disclosure | cached datasets of one workspace shown in another | mitigate | `["ws", tenantId, ...]` keys (plan 03-23); URL params reset on switch |
| T-03-30-03 | Tampering | malformed `page` or `keywords` in the URL | mitigate | clamped parsing (page at least 1, keywords at most 128 characters) before requests, gallery test cases |
| T-03-30-04 | Elevation of privilege | members shown the owner-only link in the notice | mitigate | the link renders only for owner and admin; the member sentence is shown otherwise |
| T-03-30-05 | Denial of service | double submit creating duplicates | mitigate | `inFlight` guard and `aria-disabled`; the server lock from plan 03-14 answers duplicates with 409 |
