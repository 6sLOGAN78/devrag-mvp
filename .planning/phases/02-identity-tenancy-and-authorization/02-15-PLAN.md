## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client -> settings endpoints | user-controlled nickname, avatar bytes, passwords |
| user row -> responses | secret columns adjacent to profile fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-65 | T | avatar carrying HTML or SVG for stored XSS | mitigate | magic-byte check, only PNG, JPEG, WebP, 256 KB cap, stored as data URL and rendered only in img |
| T-02-66 | I | password or hash in responses | mitigate | DTOs, leak test on every endpoint |
| T-02-67 | E | stolen session changing password without current password | mitigate | current password required, per-user rate limit |
| T-02-68 | E | session surviving a password change | mitigate | token rewritten to INVALID_ in the same transaction, cookie cleared (D-08) |
| T-02-69 | E | caller supplies another user id | mitigate | principal from the gate only; no id in request bodies |
| T-02-70 | D | oversized settings body | mitigate | body caps 400 KB and 2 KiB |
</threat_model>
