# Container Services

## Level 1: Conceptual Explanation

RAGFlow separates concerns into modular container services. Each service handles a distinct task in the RAG pipeline—from HTTP REST handling, background ingestion tasks, vector index storage, SQL persistence, binary object storage, to isolated sandbox code execution.

---

## Level 2: Implementation Details

### Service Specifications & Roles

#### 1. `ragflow-cpu` / `ragflow-gpu`
- **Role**: Core application service container executing Nginx reverse proxy, Go server API (`ragflow_server`), Python REST API server, and task executor background processes.
- **Source Configuration**: [`docker/docker-compose.yml:L21-L126`](file:///home/logan78/Desktop/ragflow/docker/docker-compose.yml#L21-L126)
- **Ports Exposed**:
  - `80` (`${SVR_WEB_HTTP_PORT}`): HTTP Web UI
  - `443` (`${SVR_WEB_HTTPS_PORT}`): HTTPS Web UI
  - `9380` (`${SVR_HTTP_PORT}`): Python Web REST API
  - `9381` (`${ADMIN_SVR_HTTP_PORT}`): Python Admin API
  - `9382` (`${SVR_MCP_PORT}`): Model Context Protocol Server
  - `9384` (`${GO_HTTP_PORT}`): Go High-Performance Server
  - `9383` (`${GO_ADMIN_PORT}`): Go Admin Control Endpoint

#### 2. `mysql`
- **Role**: Relational store for user accounts, API keys, dataset definitions, document metadata, prompt templates, and chat execution logs.
- **Source Configuration**: [`docker/docker-compose-base.yml:L207-L234`](file:///home/logan78/Desktop/ragflow/docker/docker-compose-base.yml#L207-L234)
- **Init Script**: Initializes database schema from [`docker/init.sql`](file:///home/logan78/Desktop/ragflow/docker/init.sql).

#### 3. `minio`
- **Role**: S3-compatible object storage server storing uploaded raw documents (PDF, DOCX, PPTX), parsed layout images, and chunk artifacts.
- **Source Configuration**: [`docker/docker-compose-base.yml:L235-L255`](file:///home/logan78/Desktop/ragflow/docker/docker-compose-base.yml#L235-L255)

#### 4. `redis` (Valkey 8)
- **Role**: High-speed in-memory data store for user auth sessions, rate limiting counters, task status tracking, and LLM cache.
- **Source Configuration**: [`docker/docker-compose-base.yml:L256-L273`](file:///home/logan78/Desktop/ragflow/docker/docker-compose-base.yml#L256-L273)

#### 5. `nats`
- **Role**: High-performance message queue with JetStream persistence for asynchronous task execution queues.
- **Source Configuration**: [`docker/docker-compose-base.yml:L289-L308`](file:///home/logan78/Desktop/ragflow/docker/docker-compose-base.yml#L289-L308)

#### 6. Search Engines (`infinity` / `es01` / `clickhouse` / `opensearch01` / `serenedb` / `oceanbase`)
- **Role**: Hybrid vector search & text retrieval database backends.
- **Source Configuration**: [`docker/docker-compose-base.yml:L2-L179`](file:///home/logan78/Desktop/ragflow/docker/docker-compose-base.yml#L2-L179)

#### 7. `sandbox-executor-manager`
- **Role**: Privileged microservice spawning sandboxed Docker containers to safely execute Python/Node.js code generated by LLM agent workflows.
- **Source Configuration**: [`docker/docker-compose-base.yml:L179-L206`](file:///home/logan78/Desktop/ragflow/docker/docker-compose-base.yml#L179-L206)
